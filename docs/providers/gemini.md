# Gemini Developer API

M1 retains official Google Gen AI Go SDK integration for **authenticated connection checks and verified model discovery only**. Gemini image generation is disabled in both the API admission path and worker because current image models require paid billing. Use [free image providers](free-providers.md) instead.

Optional discovery-only setup: obtain a permitted key through [Google AI Studio](https://aistudio.google.com/app/apikey), save it in Connections under Gemini, and test. The server encrypts the key, queries the catalog and marks verified image models unselectable with a billing explanation. No image is generated by connection tests.

The adapter uses `google.golang.org/genai`, bounded pagination, a five-minute credential-fingerprint cache and an exact documented image-model allowlist combined with returned `generateContent` support. Unknown text models and name guesses are excluded. Key resolution rechecks ownership/revocation before cache access. SDK submission retry attempts are explicitly one; fixture tests cover ambiguous 503 behavior. Its internal Submit implementation is never exposed by the free-only production API/worker.

Official sources reviewed 2026-09-29: [pricing](https://ai.google.dev/gemini-api/docs/pricing), [image generation](https://ai.google.dev/gemini-api/docs/image-generation), [API key guidance](https://ai.google.dev/gemini-api/docs/api-key), [quotas](https://ai.google.dev/gemini-api/docs/rate-limits) and [Go SDK](https://pkg.go.dev/google.golang.org/genai). Veo video remains later milestone work and must satisfy the no-paid-service requirement before activation.
