# Security Policy

Open Flow is pre-release. Only the current main branch receives foundation fixes; there are no supported production releases yet.

Do not disclose vulnerabilities in public issues. Use GitHub's private vulnerability reporting if enabled at https://github.com/Lord-shaban/open-flow/security/advisories/new. If unavailable, contact the repository owner using a private contact method listed at https://github.com/Lord-shaban and request a disclosure channel before sending exploit or credential details. Do not invent a project email address.

Include affected version, impact, a minimal reproducible example and suggested mitigation. Never send real provider keys or another user's data. Response timing is best-effort until a staffed release exists.

M0 has no credential ingestion or generation endpoints. Later milestones require encrypted credential storage, ownership checks, safe media egress and private artifacts before deployment.
